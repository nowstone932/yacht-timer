TACK 요트 타이머 · 작업 안내 (2026-11-24 개편)

실행
- index.html을 브라우저로 직접 열면 된다. 설치·빌드 없음.
- 부저 감지(마이크)는 PC 브라우저에서는 파일로 열어도 동작한다. 휴대폰에서 쓰려면 https 주소로 올려야 한다(예: GitHub Pages). 휴대폰 브라우저는 https가 아니면 마이크를 막는다.

파일
- index.html  화면과 디자인(요트 스톱워치 형태)
- app.js      버튼, 음성(TTS), 마이크 연결, 설정 저장
- core.js     타이머 계산, 안내 방식(고정/커스텀), 부저 감지 엔진, 신호 매칭
- i18n.js     6개 언어 화면 문구와 음성 문장(한국어·English·日本語·中文·Español·Français)
- reference/  예전 기획서·검증 기록 (개편 전 내용)

이번 개편 내용
1. 안내 방식
   - 기본(고정): 1분 전까지는 매 분 "n분 전"만, 마지막 1분은 50·40초, 30초부터 매초, 출발.
   - 직접 설정: 매 분/지정한 분만, 마지막 1분의 간격(끔·5·10·15·20·30초), 매초 카운트다운 시작 초.
2. 부저 감지 (📯 버튼)
   - 첫 부저 = 출발 순서의 첫 신호(5분 순서면 5분, 10분 순서면 10분)로 자동 시작.
   - 이후 부저는 예상 신호(10·5·4·1분·출발) ± 허용 오차(기본 5초) 안일 때만 그 신호로 다시 맞춤. 그 밖의 경적(다른 코스, 개별 리콜 등)은 무시하고 기록만 남김.
   - 감지 조건: 소음 바닥보다 감도만큼 크고(높음 10 / 보통 15 / 낮음 22 dB), 0.3초 이상 이어지고, 음정이 있는 소리. 짧은 충격음·바람·물보라 같은 잡음은 거름.
   - 맞추는 기준은 "감지가 확정된 순간"이 아니라 "소리가 시작된 순간"(약 1ms 단위)이다.
   - 잘못 맞춰지면 '되돌리기'로 직전 맞춤을 취소.
   - 스피커로 안내할 때는 앱의 음성을 부저로 착각하지 않도록 말하는 동안 감지를 막는다. 이어폰 사용 시 설정에서 '이어폰 사용'을 켜면 음성 중에도 감지.
   - 본부선과 멀면 소리가 늦게 온다(100m당 약 0.3초). '부저 감지 보정'에 넣으면 그만큼 앞당겨 계산.
3. 디자인: 시계 링 + 큰 숫자, 큰 10/5/4/1분 버튼, 나머지 설정은 접는 패널. 마지막 1분은 숫자가 주황색, 출발 후는 초록 링. 화면 꺼짐 방지(Wake Lock) 지원 기기에서는 자동 요청.
4. 다국어: 언어 선택 시 화면과 음성 언어가 함께 바뀜. 설정은 브라우저에 저장(타이머 진행 상태는 저장 안 함).

- node test-detector.cjs     합성 소리로 부저 감지 12개
- node test-dom.cjs          모의 화면 통합 17개

아직 확인 못 한 것 (실제 바다·휴대폰에서 확인 필요)
- 실제 위원회 경적 소리, 바람 소리, 엔진·다른 배 경적이 섞인 환경에서의 감지율과 오탐.
- 휴대폰 마이크 입력 지연(기기마다 수십 ms 수준 예상). 영상으로 경적과 화면을 같이 찍어 비교.
- 각 언어 음성이 기기에 설치돼 있는지, 블루투스 이어폰 지연.
- 화면 잠금·백그라운드에서는 브라우저가 마이크와 음성을 멈출 수 있음. 화면을 켜 두고 사용.
- 공식 기준은 시각 신호(깃발)다. 소리는 보조 수단으로 쓰고 실전 전 반드시 비교 검증.
